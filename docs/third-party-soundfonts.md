# 第三方音色清单

本仓库的代码和文档用 Apache-2.0，但**音色不是**：每个音色包按它自己的上游许可分发。下表由 `skills/code-band-bgm/assets/soundfont-packs.json` 生成，共 61 个包。

- 每个包的准确条款、作者署名和改动说明，以「许可文件」一列指向的文件为准（路径相对 `skills/code-band-bgm/assets/`）。
- CC BY 的包要求署名。用这些包渲染的作品，代码乐团会把对应许可与署名文件一起复制进作品目录，分发作品时请一并保留。
- 默认音色 `MuseScore_General.sf3` 为 MIT，许可原文见 `soundfonts/MuseScore_General_License.md`。
- 音色文件不进 git 仓库，用 `scripts/fetch_soundfonts.py` 从 Release 下载，逐个校验 SHA-256（清单 `soundfonts.lock.json`）。
