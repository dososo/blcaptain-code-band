# 可选本地风格对照

唯一运行源码为 `scripts/style_compare.py`。它比较本地音频的CLAP短窗表示，供宿主辅助观察声音差异；不识别精确流派，不证明同一录音、原创、版权安全或人工听感通过。基础创作/渲染不依赖该模块，也没有隐藏模型下载或云端服务。

## 环境与固定模型

建议另建Python3.10环境，安装 `requirements-style-analysis.txt`；它通过 `-r requirements.txt` 一并包含统一CLI所需基础依赖，单次pip命令即可，不修改基础依赖文件。当前仅macOS arm64/CPU实测。需本地ffmpeg/ffprobe。模型由操作者另行取得并检查来源，推理只接受本地目录，`local_files_only=True`、离线模式，不上传音频。

当前只支持[LAION官方clap-htsat-unfused](https://huggingface.co/laion/clap-htsat-unfused)的固定版本 `8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a`，权重卡Apache-2.0；代码依照[Transformers CLAP文档](https://huggingface.co/docs/transformers/v4.46.3/model_doc/clap)。目录必须包含：

| 文件 | SHA256 |
|---|---|
| `pytorch_model.bin` | `1cd3c601bc4afe0fa87be3de4c13dd2cfadd249fac1e29acf74a9b296c3219bb` |
| `config.json` | `9efb9557bc804f2ca6e394486af2e45dfed0b18554909735a99c6220b84e4288` |
| `preprocessor_config.json` | `9739f58296aa6f9ac18008fd0150fb2649bc554985fbde86d0a4041c882ac753` |

权重约615MB，不随Skill捆绑。其他检查点不能静默替换。本机测试的音乐专训 `larger_clap_music` 将明确语音、白噪声和静音映射得过近，未采用其风格排名；不能只因模型名含music就信任。

## 输入与调用

函数签名：

```python
compare_style(inputs_path, model_path, out_path, batch_size=4, rms_target=0.1,
              max_total_audio_seconds=600, max_windows=128)
```

输入JSON示例（路径是示意，不是已交付资产）：

```json
{
  "reference_source_id": "reference",
  "sources": [
    {"source_id": "reference", "path": "参考.wav"},
    {"source_id": "candidate", "path": "候选.wav"}
  ],
  "speech_control_path": "自有明确语音对照.wav",
  "speech_control_owned": true,
  "speech_control_text": "这段自有录音里实际朗读的已知原文。"
}
```

宿主应依据已获授权使用合法本地音频；本程序不取得远程参考，不绕登录、不读Cookie。语音控制必须是已有自有录音或本地离线合成的明确语音，10—60秒；记录已知原文，不把参考或候选音频改名充当对照。不要为已有合法授权重复询问用户。

至少两份来源，ID唯一；只验证单/双声道、至少10秒、解码有限的音频。单文件复用本地分析100MB上限，音频总时长最高600秒、窗口最高128、批量最高4，超预算失败，不静默抽样或缩短。拒绝URL、播放列表与间接媒体；ffmpeg/ffprobe复用 `audio_tools.INPUT_FLAGS` 的协议和解复用格式白名单，在探测前就限制间接资源格式。所有路径作为参数数组数据传入，不拼shell。已有输出目录一律拒绝覆盖。

## 先校准，后输出比较

固定10秒、5秒步长、48kHz、双声道算术平均。默认逐窗线性增益至RMS0.1并保持峰值≤0.99；受峰值约束未达目标时保留真实RMS。可以显式传None保留原幅度，不改变音符或配器。

先检查权重完整与有效输入，再运行同波形、音量乘0.25、低通、变速、自有明确语音、固定种子白噪声、数字静音对照。固定模型粗校准要求：重复与显式音频投影差≤1e-6，增益阳性余弦>0.8，三项已知阴性余弦<0.5。这是当前检查点的保守负对照规则，**不是通用音乐阈值，更不是“同风格分数线”**；有大量讲话的参考可能无法通过，应报告校准失败，而非给虚假的风格排名。不允许调阈值以追求预期结果。

校准失败返回 `status=失败`、`code=style_calibration_failed`，保存全部控制分数，`pairs=[]`，不计算/返回候选风格排名。输入或依赖错误抛ValueError/OSError等，由统一CLI捕获成JSON失败；不能返回假成品。

成功只表示测量与粗校准完成。输出保存可追踪源摘要、逐窗起点/RMS/波形摘要、512维嵌入、完整余弦矩阵、窗口分位数与质心余弦。`status_scope=audio_embedding_measurements_only`，`style_acceptance=待人工核准`。同曲身份需独立声学指纹或其他证据；本模型对25%变速仍可能高相似，不能代替精确节拍、律动或听感核验。相邻重叠窗不是独立统计样本，最高窗分数受候选长度影响，不能单看最高值。

本次真实对照与负对照证据见项目报告 `reports/本地风格对照证据_20261031.md`。Skill运行不读取项目work目录，项目旧脚本仅为薄入口，不维护第二套推理逻辑。统一CLI由宿主入口注册 `compare-style`，具体参数以当前 `band.py compare-style --help` 为准。

## 固定窗口声学差异：先定位，再修改

`audit-reference`不需模型，接受真实本地参考和候选，输出固定同规格窗口的描述符和源/解码摘要：

```bash
python3 skills/code-band-bgm/scripts/band.py audit-reference --reference 参考.m4a --candidate 候选.wav --reference-start 43.27 --candidate-start 20 --seconds 20 --out 新对照.json
```

每次1至30秒，统一48kHz双声道；拒绝不完整窗口、近静音、非有限值和缺少20Hz以上有效能量的输入。左右声道分别算谱再平均，避免反相抵消；不先把stereo折为mono。输出七段归一功率、频谱质心、峰均比、相对RMS分位、包络调制峰及mid/side能量。0.1.1另输出每频段`band_side_energy_fractions`和差值，复用相同Welch窗与频带，计算S/(M+S)；低于总谱功率1e-12的频段记null，避免用几乎无声的频带认声场。总宽度相近仍可能把宽度放错频层，必须连同频段能量、时间变化与原mix审查，不能为追宽度做反相。内部同波形乘0.25验证频段比例不随等量增益变化。包络峰不是BPM或鼓件标签，频谱相近不是同风格阈值。

队长否决参考风格后，先保留旧曲及反馈。比较选定同类段落；声部修改实验尽量保持同一原创主题、音区、和声和速度，并记录父谱/事件差异。分别核四件事：

1. 真实音源能否发出所需起音/延音，而不只看预设名；慢起音Pad可能吞掉谱面短音，加音量不能恢复瞬态。
2. 重音间距、细分和留白。相同BPM可有不同半速拍感；等距八分镲不等于有滚奏和呼吸的律动。
3. 低音门控与中频叠加。延长sub会增加实际能量，必须重查声部贡献，不能照搬原增益。
4. 声场和明亮度。声像平移与宽度不是同一件事；不能为了“柔和”盲目低通本已偏暗的新曲。

需要分离时使用已登记的本地Demucs等成熟工具，双输入应同采样率、声道、模型和设置，并用已知新曲事件交叉核起音。分离stem会泄漏，不能当真实分轨、精确鼓件、逐音旋律或和弦真值，不复用参考stem作新曲素材。

短对照准备可先测FFmpeg ebur128，再各自施加固定线性增益至同一安全LUFS，复测真峰值；保留原幅度和处理参数。不用补静音、压缩或变速使指标好看。参考对照片段只留本地分析目录，不打进Skill或新曲包。自动测量、原始模型估计、人工听感及用户风格接受分别记录；任何一项都不能代替另一项。一次短预览定位的问题才允许修正重渲染，不盲反复长渲染。

音乐声学风格条件生成属于另一种后端能力，必须核查参考实际进入条件路径、许可、模型体积、离线运行和旋律/原录音复用边界。音频生成模型输出不自带逐音符可编辑乐谱，不能冒充代码乐团原有引擎或“保留旋律”精确修改。未经本机实际实验，不作为已支持后端宣传。
