# 音体、空间和多音干扰

先用真实已知音源核方法，再分析参考。将声源的谐波与包络、效果造成的变化、同时演奏的其他音高分别记录。未知混音通常没有唯一干声解，不能把一个分离轨或较小残差当作原音色真值。

## 可调用的局部联合观察

`inspect-harmonics`复用SciPy 1.15.3的`linalg.lstsq`，同时拟合给定候选音高的正弦/余弦基。候选由宿主依据已有音高分析提供，第一项是目标；它不是全盲音符识别器或去混响器。

```sh
python scripts/band.py inspect-harmonics --request 观察请求.json --out 新观察结果.json
```

请求如下，音频路径相对请求文件解析，摘要需替换为真实SHA256：

```json
{
  "schema_version": "1.0.0",
  "audio_file": "观察音频.wav",
  "audio_sha256": "替换为实际64位SHA256",
  "observations": [
    {
      "observation_id": "候选身体",
      "start_seconds": 0.12,
      "end_seconds": 0.16,
      "f0_candidates_hz": [172.6, 307.3, 410.3]
    }
  ]
}
```

输入限30秒内双声道音频，1至32个观察窗，每窗20至500ms、1至6个不重复候选。时间先按原始秒数检查，再记录实际分析采样率/帧区间；不得靠取整接受越界。请求及音频都绑定SHA，运行中变动、非有限音频、共频目标根或无有效根会明确失败，输出不覆盖。

音频以SciPy重采样至16kHz；每组至多32个谐波、频率低于7.2kHz。相距不超过10Hz的频率基合并，涉及不同候选组时标为共有，不能将同一能量重复分给两件乐器。输出有逐谐波幅度/比值、共有项、秩/条件数、残差及M/S观测。条件数阈值仅适用于当前研究的数值判定，不能证明原器、干声或完整分离。目标投影能量比也不是已知源的保留率或分离纯度。

## 将结果用于音色重建

1. **已知控制先行。** 原音体/MIDI不变，分别加已知效果和独立干扰；同时保存真分轨。限定两音高拟合一个共享模型，参数冻结后在新音高/新重叠布局评价，不能用留出重新调参。
2. **分清短早窗的成立条件。** 已知音符起点、短起音和晚于观察窗的首个回声，可以支持早窗近似干音。原曲聚合触发不一定是目标noteon，前一音尾声也可能仍在；不能照搬“前35ms就是干声”。
3. **保留低根/高八度竞争。** 若只建上方强峰会漏掉低部与奇次成分，需检查其真实幅度与跨时共变。更完整的复合频率模型仍不等唯一物理乐器；同时和声可能共用谐波。
4. **音体与空间分开存。** 静态或少量谱帧只作为有限音体候选；效果参数、干湿输出和真实处理器单独保存。估计轨的空间趋势可能与原mix相反，不能直接截其尾巴当原混响IR。HPSS将持续回声留在谐波部也很常见，不能把H叫干声、P叫其他乐器。
5. **演奏新旋律。** （v1 不含插件演奏路径，需另行接入合成器）运行只读完整状态和新MIDI。新主题不读原音符轨迹；保干声与空间版便于查音体问题。原语境、分离估计和新主题分别标注，等响度比较后再决定是否回乐团。

如果原空间/干扰无法唯一分离，结果应叫“含不确定性的复合音体候选”，仍可交付其演奏新主题的研究短样；不能把它改名为原器恢复成功或用它绕过音乐方向验收。原曲频率轨迹重放与新旋律必须分开。

## 声音随时间运动的核查

对同一时窗同时记录混音、分离估计及其他候选的起音、持续、不同频带的绝对中侧能量和比例。比例升高可能只是另一分量下降，不能据此认定空间真的扩张；分离代理的起音变化也可能来自鼓或邻音泄漏。逐频带报告实际分析窗长度，不把宽窗估计当毫秒级事件，也不把分离轨名当物理乐器。只有已知源控制或实际聆听才能进一步检验这些竞争解释。

跨段判断声部是否进入或退出时，还需同口径比较原混音与分离估计的频带活动，并检查分离残差。某个代理在一段显著变弱，若原混音同频带仍稳定且残差较大，不能直接判定原声部退场。鼓频段的周期及共起只能支持声学节奏候选，不能直接换算具体鼓件数量；鼓低音压制同样需要在各窗口有一致证据。
