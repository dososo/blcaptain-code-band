采样与代码分开：MuseScore主库MIT；VCSL、FreePats、作者二胡/箫及曼陀林录音CC0；古琴、PipaSet及特定旧版笙CCBY4；京剧以取得包内CCBY3为准；Iowa按作者任意项目使用声明登记LicenseRef-Iowa-MIS，不改称CC0。准确条款、署名、变更和来源摘要以各库的许可文件和source_manifest为准。

CCBY许可和署名文件随使用该库的生成作品复制，使用者应保留它们。它们不证明所有音色达到专业质量，也不保证新作不存在与其他音乐相似的片段。

引擎与依赖使用系统或独立环境，不把其许可转换成项目许可：FluidSynth为LGPL，MLX-Audio为MIT，FFmpeg以本机实际构建许可为准（本机GPL构建），SF2cute制库工具为Zlib/libpng；可选依赖分别遵循上游许可。未将这些工具的修改后二进制混入本技能。

Qwen2-Audio社区量化与当前CLAP权重分别按Apache2记录，模型另行显式安装，不随候选包打包，也不自动下载。MOSS公开权重Apache2不等于社区MLX适配代码已获再分发授权；该研究目录和约10GB权重均不进入本包，尚未成为正式生产依赖。

参考音频、分离轨和用户演示视频只留本地分析，不进入公开候选包或成品混音。合法使用已有授权不需要重复形式化确认；付费库与仅准音乐使用、禁止采样库分发的来源没有被重打包。
