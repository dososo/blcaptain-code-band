# 参考创作反复失配时的路线选择

本页约束方法选择，不提供自动好听度评分，也不把研究后端设成必装依赖。先用`python scripts/band.py knowledge --rule V31-K03 --rule V31-K04 --rule V31-K06`取得来源和反证。

## 先把问题分清

| 目标 | 当前可复用 | 需要补的证据 |
|---|---|---|
| 文字创作、可编辑谱、逐音修改 | 宿主写新主题，现有采样/插件、编译和渲染 | 音乐质量及具体真实奏法；没有参考无需被参考理解门槛阻塞 |
| 从混合录音理解参考 | 录音身份、节拍、分离/转录候选、局部观察 | 稳定的音频感知和音乐关系；标签或分离轨名不能签原器 |
| 恢复可演奏音色 | Surge等真实引擎；共享参数和新音高演奏 | 音体动态、噪声/偏频、空间及跨音高/力度的泛化，不能只过同族静态控制 |
| 参考条件音频基准 | 可选成熟本地模型、固定输入和执行证据 | 风格/主题独立性及可编辑能力；仅音频输出不能冒充逐音乐团 |

知识库与Skill文件不会训练宿主的听觉。MUSE与核心感知实验区分读谱推理、音色分类和关系感知；MuseDiag也明确其短属性诊断不覆盖稠密复音、空间和表现细节。不能从排行榜、提示词或名校资料数量推导本宿主已经听懂参考。

## 已被证据否定的默认做法

将未知复合主奏压成两帧整谐波幅度，再配任意ADSR和混响，不能作为默认参考音色恢复。该工具可以保留作可演奏诊断；它通过简单同族控制不能支持复杂源。先给真实复杂音色的真F0/起音，检查攻击、身体、释放、左右动态及未拟合窗；如果模型本身表达不了，不再用更多拟合轮数补救。

反复失配时保持原音乐目标：鼓/低音/有调重音如何叠成节奏，主线如何延续、发展和交接。局部音色实验完成，不自动成为新BGM方向通过。分维度保留用户已认可的结果；负控静音只定位声音，不能直接当删职责处方。

## 当前推荐：保留乐团，另设有界音频基准

复用已安装且许可、资源预算适合的ACE-Step参考条件分支，可作为有界研究对照。此前名义16秒基准经用户试听否决，且实际约9秒后近静音；帧数和整曲非静音并不证明有效音乐覆盖。已在该固定案例中定位自动掩码错误并作隔离修复，旧基准及其否决状态保持。不能将该基准当参考风格通过，也不承诺其它机器的结果。没有这些本地依赖的宿主不得标记已具备该后端。

### 固定ACE版本自动掩码修复（可选）

后续固定条件实验证实，上述近静尾案例受该ACE版本`auto`掩码错误影响：官方源码把`2.0`写入布尔张量变成`1`。只修该条件并保持随机流，真实八步与官方VAE生成的16秒全段活动通过覆盖检查；这不代表参考风格、主题独立性或其他生成请求均已通过。旧候选和用户否决不变。

有匹配的本地ACE环境时，可由其调用方在**同一handler实例、整个生成调用期间**显式使用：

```python
from optional_ace_mask_fix import corrected_auto_mask

with corrected_auto_mask(handler):
    result = generate_with_existing_handler(handler)
```

`generate_with_existing_handler`是宿主已有的调用入口示意，不是技能内可直接调用的函数。包装器严格核官方固定源码SHA，仅修返回的自动掩码行，保留显式模式和重绘掩码；退出或异常时恢复实例方法。未知版本明确拒绝，不修改上游文件，不以Torch或ACE作为普通乐团的必装依赖。完整重绘听感、并发调用和其他版本均未验证；此处不是可直接调用的统一生成命令。

- `reference_audio`是参考条件，`src_audio`和`audio_codes`承担不同内容路径；以源码和现场参数核准。本参考新作实验禁止把原曲放进source/codes或cover。
- 短参考可能被模型内部重复并取窗。记录真实有效内容长度，固定Python/NumPy/Torch/MLX等实际使用的随机流；不能把重复后的30秒当30秒独立观察。
- 参考条件仍可能携带旋律/和声信息，禁止据接口名保证原创；这类输出先标音频研究候选，主题复用与听感另验。
- 使用现成模型也要保代码、权重、文本编码器、参考录音各自许可。MusicGen-Style权重的非商业条款、Stable Audio的模型条款不能被工具代码MIT覆盖。
- 内存不足先查模块生命周期。可冻结官方条件→官方扩散→官方VAE分进程，保持精度、全部参数、真实配置和摘要；它是项目薄适配，不是另造音乐算法。原生位深与最终PCM规格分开检查。
- 重新编码条件可能有浮点漂移。需要复演时冻结实际条件；一次潜变量复演一致也不能扩写成完整WAV或跨平台位级保证。

本轮研究驱动尚未作为通用生产CLI发布；核心统一`knowledge`和`check`入口已经可用。不要编造`assess-goal`或`render-neural`等未实现命令。完整谱、声音绑定及保旋律修改仍走已有乐团接口。

## 何时再回作品

有声音相似的独立研究产物后，核主句、节奏组、持续层和前后交接，形成可执行的新主题/演奏方案；不能直接将生成模型音频转录后就报告精确可编辑。当前用户明确要求短样先行、已否决的参考方向，在实际接受前不扩写三分钟。普通无参考创作继续合理默认、直接推进。

人工评审看具体WAV：节奏推动、可回认且发展的主句、音体/层次和情绪是否满足用途。技术状态、分析可靠性、主题独立性、音乐接受、宿主实测分别保存。不能要求不懂乐理的用户先列出原器，才能承担这些验证责任。
