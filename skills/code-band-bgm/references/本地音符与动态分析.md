# 本地音符候选与动态关系

需要局部复音时序辅助证据时使用，普通一句话创作不强制安装。音频仅在本机解码和推理；不自动下载模型、不上传、不嵌入付费服务。输出是分析候选，不是可宣称准确的原乐器表、和弦或新曲乐谱。

## 明确复用范围

复用[mt3-infer的YourMT3推理子树](https://github.com/openmirlab/mt3-infer/tree/d8cbd287470291dee335f84315c5a9b9ff6e6c8a/mt3_infer/models/yourmt3)，固定提交`d8cbd287470291dee335f84315c5a9b9ff6e6c8a`。只取该子树，保留其LICENSE/NOTICE和上层MIT许可；父级使用Python命名空间，不导入整个仓库注册入口或其他MT3分支。上游为去训练框架的第三方适配，不能报告成原作者未修改代码。

模型为[作者YourMT3固定版本](https://huggingface.co/mimbres/YourMT3/tree/e45ebd70398682d54b7bb1901a5216e18f3b1824)，路径`logs/2024/mc13_256_g4_all_v7_mt3f_sqr_rms_moe_wf4_n8k2_silu_rope_rp_b36_nops/checkpoints/last.ckpt`，561544628字节，SHA256为`ae38e415c79efd5592dcb9b658cdb99ddb11d4c4e1eaa364cab04a052473fc25`。作者模型卡声明Apache-2.0，源码/模型/依赖分别保留原文，不将模型许可外推到所有资产。权重和第三方子树不捆绑技能核心；只使用已核来源及摘要的checkpoint，加载格式涉及Python反序列化，不能接受任意用户模型替代。

本机实测环境为macOS ARM64、Python3.12.9、Torch/torchaudio2.9.1、transformers4.45.1、tokenizers0.20.3、mido1.3.3、packaging23.2，CPU FP32、batch1、4线程；单次模型常驻峰值约2.72GB。四个较小包可安装到独占target目录，Torch及其依赖由隔离解释器环境提供。不要把`--no-deps`用于全新空环境后声称依赖完整；本机复用了已存在且可导入的基础环境。不同系统须重新取得适合其Python/架构的轮子并验证，不复制macOS二进制轮子到Linux。

## 登记与执行

由操作者从上述固定来源准备资产，并把子树放在`来源代码/mt3_infer/models/yourmt3/`。不需要复制上游顶层`__init__.py`。检查独立环境可导入torch、torchaudio、numpy、scipy、soundfile和其余运行依赖；将四个固定版本包及所需依赖安装到独立目录，避免覆盖宿主环境。随后封存实际文件：

```sh
python 技能目录/scripts/register_note_backend.py \
  --source-root 本地资产/来源代码 \
  --dependencies 本地资产/依赖 \
  --checkpoint 本地资产/YourMT3_MoE_noPS.ckpt \
  --expected-sha256 ae38e415c79efd5592dcb9b658cdb99ddb11d4c4e1eaa364cab04a052473fc25 \
  --source-commit d8cbd287470291dee335f84315c5a9b9ff6e6c8a \
  --out 本地资产/模型配置.json

python 技能目录/scripts/band.py analyze-notes \
  --input 本地参考.wav --model-config 本地资产/模型配置.json \
  --backend-python 隔离环境/bin/python \
  --start 0 --seconds 8 --prefix-seconds 0.25 --out 新候选目录
```

登记只校验文件与显式期望模型SHA，写相对配置路径；不会安装、运行模型或独立证明上游身份。配置记录源码`.py`和target依赖全部非缓存文件集合及摘要；运行时先核集合和摘要再导入，权重655键严格加载，缺键/多键失败。其他系统包如Torch并未由该文件锁覆盖，真实版本另记。配置和资产一起移动保持相对结构可重定位；不把路径可配置当跨平台已通过。

主运行器需其正常音频依赖与FFmpeg；模型在显式指定的另一解释器子进程执行，保留venv解释器路径，不解析成系统Python。窗口0.5至30秒，前置上下文仅支持已验证的0或0.25秒。worker禁用socket联网/HF在线访问，每clip限180秒、RSS限6GiB，父进程总限210秒；这不是恶意代码沙箱。目前仅macOS实测；Linux已处理RSS的KiB单位但未实测，Windows的resource/SIGALRM不支持，明确失败，不宣传所有系统即装即用。

新目录成功发布后含`analysis.json`、实际输入短窗、backend.log、raw tokens/合并错误/候选。失败保留临时诊断，不发布假成功。`status_scope=multitrack_note_candidates`仅说明执行与数据契约有效，不代表音乐核准。

## 如何使用结果

先在当前模型和环境跑已知演奏、静音及布局/增益控制，再看参考mix与分离估计；原始错误必须保留。窗首tie无可靠onset时标左删失，不补造；块末offset可能右删失，不当实际音长；窗外候选保留在排除列表，不静默裁切。模型velocity为活动标记，不是录音真实力度。

本机已知钢琴3音正控：无上下文首次漏窗首音，0.25秒前置静音后3/3恢复。原other同窗调整前置上下文后候选集合明显变化，program在Piano/Strings间漂移；自有FM/clean guitar技术片段零候选，正控失败。这些反证使其只能辅助复音运动/候选时序，不能用于选原preset、自动确认和弦或识别准确率承诺。参考notes不直接输入原创生成；宿主重新写主题与发展方式。

鼓低音关系可交叉复用librosa0.11谱通量/HPSS/CQT，但它们不是独立乐器识别器。保留未量化时刻、峰对齐音体和频段描述；以已知真实击打的一对一容差控制验证起音，再比较低音在低频冲击前后与半拍负控的变化。分离估计的互补变化可能是伪动态，原混音低频和边界敏感性须另核。若需要自有让位处理，使用[显式duck](延迟与空间.md)，不得称反推出原效果。
