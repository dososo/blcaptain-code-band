# 本地分离与角色证据

适用：参考创作连续失配，需核查鼓、低音、和声节奏和前景，而语义模型描述不稳定。复用官方 Demucs 的六源估计、本地拍点/频率分析与已知演奏控制；不用上传参考。轨名、模型 program、流畅描述都不直接决定原乐器。

## 六源入口

核心不导入 Torch。先在独立 Python 环境准备 Demucs 4.0.1 / Torch 2.2.2，再显式登记已有官方 `htdemucs_6s` 权重：

```sh
python scripts/register_separation_backend.py \
  --checkpoint /操作者选择的目录/5c90dfd2-34c22ccb.th \
  --backend-python /隔离环境/bin/python --out /新目录/分离配置.json
python scripts/band.py separate-reference --input /本地目录/参考.wav \
  --model-config /新目录/分离配置.json --backend-python /隔离环境/bin/python \
  --start 60 --seconds 8 --out /新目录/分离结果
```

路径均为操作者选择的占位符；配置内模型与源码使用相对路径。没有自动安装/下载。权重完整 SHA256 为 `34c22ccb381c6f9fdbf324f04e1e2fe21aaaf293f5ded163a162697ff9a02ddd`；上游 [Demucs](https://github.com/facebookresearch/demucs/tree/e976d93ecc3865e5757426930257e200846a520a) 为 MIT 项目，官方提醒六源模型的 piano 效果有限。项目许可不扩大为参考录音再分发许可。

窗口为 0.5–30 秒，44.1kHz/双声道/FLOAT32 **分析副本**；交付六份估计轨、重构和残差、原始报告、版本、模型/源码/输入摘要及实际参数数组。CPU 两线程、FP32、网络关闭，后端 3GiB/180 秒、父进程 210 秒守护。失败保留 `.separate-*` 取证目录，不发布成功目录。配置锁定源码集合、版本与摘要，不宣称封存全部系统二进制或支持任意版本。

逐轨重新核帧数、有限数、摘要、重构加和及残差。禁止把低能泄漏轨归一化后称为已找到吉他/人声；均值恢复可能带入 DC。FM 音色也可能进入 `piano`，所以该文件名不是物理钢琴证明。不能把分离轨回混或剪成新作采样。

## 将可信的局部观察交给宿主编排

先保留真实来源身份、观察窗及竞争解释，再汇总四种角色。不要要求自然语言模型为已经有独立测量的事实盖章；也不能用结构校验替代音乐判断。

`reference_understanding.method=local_role_analysis` 支持本地角色证据包。入口仍是 `render --reference-analysis`，证据包的范围必须为 `analysis_scope=local_role_measurement_evidence`，字段如下：

- `source.file_sha256`：与本次参考测量源一致。
- `windows`：实际源坐标的 `start_seconds` 与 `duration_seconds`，有限、非负起点、正时长。
- `evidence`：非空记录，含唯一 `evidence_id`、相对包父目录的 `path`、真实 `sha256`、`kind`；类型限 `measurement/source_separation/controlled_render/official_comparison`。
- `observations`：`drums/bass/harmonic_rhythm/foreground` 分别含非空 `observation`、`limitations` 列表及引用上述证据的 `evidence_ids`。
- `composition_ready=false`，`manual_listening` 为“未进行”或“待人工验收”。

分析 JSON 的四维观察/新作实现/声部映射、参考身份门禁仍然有效。这个契约只验证可追溯来源、实际文件和限制声明，不证明文本内容正确。宿主必须审阅报告的控制、反证和适用范围，不能随便拿一个报告哈希签收配器。作品打包小报告并重写相对引用，同时保存输入证据包摘要；无需捆绑参考音频或模型。

## 三类问题分开排查

1. 接线：用官方处理器的同一输入、同一完整权重、严格加载与中间张量比较移植实现；保留源码提交和依赖版本。模型回复相同不等于听懂。
2. 量化：固定模型变体、输入、提示与解码条件，只改精度；单层误差、少数位置 argmax 一致不能外推全模型语义等价。
3. 能力：已知音色/布局、静音、域外和增益控制仍失败时，限制该任务用途。改用适配任务的专用分析及真实载体对照，不能反复改提示或把另一句描述当新事实。

单声道 16kHz 语义输入无法直接判断原立体声声像与 8kHz 以上高频；这些用原始双声道全带宽测量。持续低频、低打击和高频细节分开；快慢拍等价不等于可以在快网格套用慢网格重音。复音转录的重触发不等于换和弦，泛音不等于多个乐器，模型块末 offset 不等于真实收音。

原声场过窄时，先测同资源真实效果是否能表达，而非换成弦乐。可选原生 chorus 见[延迟与空间](延迟与空间.md)。选用效果只是有证据的表达候选，不代表识别原效果器。完成一个短样后，技术、来源/创作审查、人工风格验收仍分别记录；方向通过才展开长曲。
