# 音乐创作基线

以下是可扩展的创作方向，不是固定曲库或全风格承诺。每次由宿主Agent设计新的主题与发展，不让简单关键词匹配冒充自然语言理解。

| 方向 | 节奏与和声 | 配器与演奏 | 结构与留白 |
|---|---|---|---|
| 温暖城市爵士 | 约80至96四分音符BPM，轻切分/后半拍，七和弦与九音色彩 | 电钢琴或钢琴、原声贝斯、轻鼓、颤音琴问答，少量时序变化 | 引入→主题→对答变奏→收束，主旋律不持续占满 |
| 克制叙事室内乐 | 约68至84 BPM，6/8或3/4分组，和声缓慢、倚音解决 | 钢琴、弦乐合奏、长笛；和弦共同起音，句间呼吸 | 稀疏引入、弦乐接力、中段抬升、完整尾音 |
| 轻快电子脉冲 | 约112至128 BPM，稳定四拍底鼓、十六分音型、少量调式借用 | 合成贝斯、方波主奏、温暖铺底、闭镲，时序锁定 | 声部逐层进入、主体、减法桥段、回归；低频职责分开 |

主旋律先写一个有节奏辨识的短动机，再做音程、节奏、方向或对答变化。避免全曲只循环一个音阶或和弦琶音。低音突出根音与经过音，和声避免长期占用贝斯音区。原声类音色只承诺当前采样库实际预设与普通奏法，不由名称推断弓法、连奏或真实演奏品质。

精确60秒可选58秒主体和2秒尾音；若音乐结构更适合其他预算，先在乐谱中解释。尾音时长不是越长越好，需要配器释音和实际末段能量支持。循环先选择能精确落在固定周期的拍数和有理数速度，并安排终点回接；不靠补静音凑长度。

参考音频仅抽象速度范围、乐器角色、律动、能量变化与质感。主题、具体节奏动机和发展需重写，不转录或变调原曲当成新作。不得把听感未验收写成“自然”“好听”或“达到商业品质”。


## “配器、曲调更丰富”的定向修改

先保留用户具体认可的维度。例如“节奏稍类似、整体仍有差距”只支持延续该节奏方向，不能当作风格已接受。保存父版本与原话，把旋律发展、声部回应、和声色彩和配器进退分别设计，再检查实际声音。

主奏应有可辨的动机、句尾和变化，伴奏为它留空间。应答声部在主句空位进入；铺底与和声改变音区/转位或段落力度，不持续加厚低中频；低音和鼓保持各自职责。更丰富可以来自两种角色的对话和段落变化，不等于全程叠满更多乐器、重复主奏八度或提高响度。未指定民族/管弦风格时，不擅自插入强烈改变整体方向的乐器。

乐谱路线记录声部、音区、起止、动机变形与冻结事件差异；音频生成路线记录本次创作条件及完整现场来源，不能把这些文字当实际配器的证明，也不能补一份无关乐谱冒充音频对应工程。一次短修订用于判断方向，技术检查与人工风格反馈分开，不能用反复抽样取代定位问题。

进一步诊断见[乐句与层次编排](乐句与层次编排.md)：优先核长短与标点、重复和定向变奏、前中背景进退以及真实音色延续。不能因参考有连续主体，就把全部和声/融合层从头铺到尾；也不能把少量长音或更多轨道当作舒展与丰富的通用保证。
