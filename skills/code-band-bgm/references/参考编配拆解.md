# 参考编配拆解：先解释角色如何配合

适用：用户要求接近参考的节奏、音色组合或编配，尤其已有风格否决时。不是常规无参考创作的参数问卷，也不要求每个步骤向用户审批。取得音频、数值测量、角色推断、诊断性试奏、参考编配候选和人工接受分别记录；目前运行器的来源/字段门禁不能判断这些音乐结论是否真实。

先看[参考理解验证](参考理解验证.md)。局部角色描述可能同时适用于很多不同风格；“连续有调主体”“低音让位”不能唯一推出FM电钢、弦乐或某套新和声。若用户整体否决，不能把反馈只改写成自己的谱需要更长音/更多进退，再继续同一路线。必须先验证参考解释和候选实现的对应关系，允许结论是当前音色字典或理解方法不足。

## 从声音到角色，避免从乐器名开始填空

选一个确实包含主要组合的短窗，同时保留完整混音和带来源的分离估计。先记录每层做什么、何时与谁配合，再提音色候选。源分离的drums/bass/other是模型估计组；other可含多个乐器，HPSS的谐波/打击/残差也不是乐器标签。

|拆解维度|需要的证据|不能由此直接推出|
|---|---|---|
|鼓与打击音色|起音、音体、尾音、噪声/有音高成分、是否叠层、实际出现位置；分离泄漏与效果影响|低频=kick、高频=hat，或最近的现有鼓模板就是原鼓件|
|律动|拍级/半倍拍候选、相对拍位、强弱、句尾/填充、稳定的偏移与留白；保留未量化时刻|相同BPM、固定第三拍、随机humanize等于相同拍感|
|低音与鼓|低音运动/持音/滑音候选、每次起止相对鼓击的分布、重音与低频职责|所有低音统一推迟某毫秒就是参考pocket或侧链|
|和声节奏与织体|和声多久变化、击发还是延续、切分/分解/持续层、音区及与鼓/主句的关系|某小调、四个和弦或几条pad轨就是同风格|
|前景与装饰|持续riff还是完整主句、是否真正换手、装饰层进入/退出、叠音与音区关系|有两个不同音色便需要接力主旋律，或用户要丰富便应加吉他/弦乐|
|空间及动态|起音保留、近远/宽度、混响尾和延迟节拍候选、声部/总线动态的依据|静态pan就是去相关，或频谱/响度相近就编配正确|

每项重要推断保留时间窗、实际输入SHA、方法/版本、观察、替代解释、未知及反证。模型标签/NNLS系数不是概率，用户的“昂扬”“丰富”不支持凭空确认乐器。能确认功能而不能确认preset时，用声音特征约束选择；连功能都不清时先做诊断，不用流派常见配器填空。

## 复用成熟方法及验证它们回答的问题

- [librosa HPSS](https://librosa.org/doc/0.11.0/generated/librosa.decompose.hpss.html)用于分开较稳定谐波与瞬态；margin大于1时保留残差。不能据两个分量计乐器数，弱起音/混响/鼓的音高尾可能分散在多个分量。
- [FMP的有约束分解](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C8/C8S3_NMFSpecFac.html)说明模板解释需要音乐信息约束。无监督NMF或只初始化模板后继续更新，不能给组件贴上真实乐器名。使用固定有标签字典时可复用[SciPy NNLS](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.optimize.nnls.html)，但字典外输入仍可能被强行投到错误模板，低重建误差不是身份或风格证据。
- 将音色与布局分开检验：同布局换真实音源、同音源改布局、常数增益正控；留出音符/力度/材料，另测去掉真实模板、标签置换及未见音源。识别音符/起音的主张还需独立真值、一对一容差及精确率/召回率，时间激活变化本身不证明起音转录准确。
- [GrooVAE](https://magenta.tensorflow.org/groovae)区分击打布局、力度与微时序；借用其分维表示与鼓/低音协作思路，不把生成器输出当原曲分析，不假设所有风格都需要随机偏移。现有事件/随机流可以保存已确定的演奏。
- 多乐器转录模型输出的program/pitch/onset/offset仍须做家族/泄漏和实际输入校准；它不是独立stems，也不能反推原preset或完整混音。比较具体版本/模型许可/CPU或GPU及缓存接口，显式安装和固定资产；不把另一个重模型作为默认补丁。

已接入的局部候选入口见[本地音符与动态分析](本地音符与动态分析.md)。实际控制发现前置静音可修复窗首tie合并丢音，但同窗前移也使program与候选集合明显变化，自有FM/吉他正控仍失败；不能据“模型运行成功”选原配器。谱通量起音也先做真实单击/增益/时间移动控制；将峰对齐的低频音体、高频短体和混合声学组当功能证据，不直接命名鼓件。核低音让位须在同一鼓触发点比较前后能量，并加半拍偏移负控与原混音互证；分离器的互补伪动态仍是替代解释，不能反推压缩器参数。

## 从拆解结论到编制决定

先形成一张简短的“参考角色→声音/演奏约束→本地资源候选→已验证/待核”表。角色的相互关系必须进入新乐谱：低音与鼓怎样咬合、和声怎样推动拍感、主句是否持续或留白、装饰层怎样衬托。真实单音探针只证明候选可演奏/有某包络，不证明这组候选就是参考组合。

尚未解决的辨别点需要试奏时，用少量中性的技术材料比较一个变量，标记为诊断性试奏；原录音和参考转录仅供分析，不混入独立新曲。等声音家族和角色关系有证据支持后，再用新的主题/节奏动机做一个代表短样。不可把诊断性材料或“我主动选择了这些音色”的说明升级为参考编配已理解。

连续同方向否决时保留旧作品与用户原话，暂停同法换预设、加轨、调增益及长曲展开；找出缺失的分析能力，换有证据的新方法。自动检查、来源/创作审查与人工听感独立记录。正常文本创作可直接按合理默认完成，以上参考分析流程不成为其不必要的阻挡。

## 厚重鼓点与多音域的具体核对

持续低音连起来之后仍薄，分别看起音、音体和尾窗的频带职责。原mix、分离估计、残差与错时/锚点敏感度共同约束，不能把含下一击的尾窗当单击release。对当前真实音色既记录同力度的实际电平，也记录匹配电平后的包络；分母、窗长、滤波方法不同的比例不能直接混比。低频很多而较高鼓身弱时，继续加sine未必补到敲击体；主拍手已有弱军鼓时，也不能虚称缺整件军鼓。

[iZotope的鼓层制作案例](https://www.izotope.com/community/blog/layering-drums-benefits-pitfalls-and-techniques)强调声音层的互补、瞬态和极性，避免低频抵消；[NI的底鼓制作案例](https://www.native-instruments.com/blogs/blog/7-ways-to-improve-your-kick-drums)区分起音、鼓身与低部。应用时先核真实采样区/力度层和重复录音别名，再用实际数组相加，不相加独立RMS冒充混合结果。包络峰对齐不等低频相位对齐；一个明确偏移反证失败后，允许放弃叠加，选择少数位置的真实音源替换，而不是不断搜偏移或默默牺牲低体。没有实现的极性翻转、总线压缩、EQ/饱和不能写成已用效果。

资源按声部分开时，需保鼓低音的触发关系。可用[显式事件包络](延迟与空间.md)的多触发并集绑定所有实际底鼓；必须经新能力证据核准，旧能力拒绝，不以静音幽灵击点补触发。替换不等新增击点；只在需要的强位换源，近邻双击、滚奏、释放段是否保留由本曲证据决定。

多音域先查实际下内声的时值、活动并集、力度与齐击关系，再看持续层的音区/共同音/变化。频带有能量不等存在独立线条，谱上有几个音也不证明参考用了几件乐器。可在保主主题的前提下，用少数反向内声、共同音延留和选择性回答重配；不会自动令整曲燃或有人味。候选新bass或预设探针通过，不构成必须加常驻声部的理由。

## 已有乐团却组合不对、持续尖亮时

先把“哪条新作声音不合适”和“原曲是什么乐器”分开。用户描述无法可靠对应时，用同一短窗、同一成品增益的少量真实静音消融；每份只移除一个实际声部，不逐份归一化，保留量化残差和源身份。截短试听末端统一短淡出，避免硬切制造新点击；不把诊断当新曲候选。用户只需认同一声音是否消失，不必替Agent命名乐器。这用于已失败的定位，不成为常规创作问卷。

有消融回执后，记录它支持的具体源、版本/窗口/差别，不升级为原配器或新曲听感已过。消融使尖线消失，只证明来源，不证明应删除该声部或它承担的主旋律/推进功能。先回未通过但可比较的完整基线，区分音区、泛音、门内包络、混合比例与写作问题；保留重要功能，隔离验证最小修法。替换或删掉主奏前须有保功能的证据，不能把诊断负控本身当创作改进。用户听感是验收信息，专业处方由Agent负责，不把小白观察扩大成技术指令。

[Aril Brikha本人在Ableton的拆解](https://www.ableton.com/es/blog/aril-brikha-remaking-groove-la-chord-with-live-and-note/)展示少数核心角色及发音、进退的配合；只借方法，不移用音符或仅限教学的素材。具体原曲若支持低频延续跨多次鼓击，不用通用“kick/bass互补”口号把低音全切成短音。已正确的鼓锚不是每次必须重写，额外固定脉冲也不自动是复合节奏或polyrhythm。

前景换载体后重做角色电平：旧配角gain不能不加判断继续当主奏，也不能靠静音/变小假装音色匹配。用真实机制和成品同窗校准，只作为工程起点，不把RMS近似当感知等响或情绪通过。控制与主样的gain、音区、和声事件、首段/后段覆盖须分别记录，变过插件事件时必须新渲，不复用旧波形冒充。

核心角色证据仍保持其测量范围；用户的源消融反馈可独立保存为user_feedback.json并关联父版本/诊断，原参考整体未人工听辨与新作品待音乐验收均如实保持。新作只做一个短样，听感方向通过后再展开。以上是分析与选择方法，不把某套中域键盘/合成器组合固化为所有风格的默认编制。

## 多窗角色关系验证

固定一个有证据的拍网格候选，在不同片段比较高、中、低频瞬态和分离代理，另设半格偏移等反证；相位稳定不自动证明小节强拍、拍号或鼓件身份。低频身体在鼓候选稀疏的位置仍存在时，可考虑新作低音延续或补位，而非逐底鼓裁成短音。某些中域增长与鼓代理下降同时发生，只支持有调主体可与鼓独立运动，不证明原曲的具体乐器或起音。跨段比较必须同时核原混音与分离残差，避免把分离器漏失当成乐器退场。
