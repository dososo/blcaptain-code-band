# 乐句与层次：让声部真正组成音乐

适用：用户反馈旋律不成句、缺舒展/韵律、织体单薄或没有层次。常规无参考创作也可按需使用。宿主负责音乐判断与写作；稳定运行器负责演奏与检查，不需再加收费作曲模型。

本文件处理已确定方向内的写作，不负责确认参考风格。v10按以下句法策略真实实施后被用户整体否决，证明“满足新作计划”并不证明“计划符合参考”。原曲方向仍不清时，先回[参考理解验证](参考理解验证.md)，不能继续套4+4+4、加长主音或更多弦乐来替代听懂参考。

## 先找真实谱面问题

选包含句中/句尾、可辨重复和内部转折的代表片段，尾音单列。读取实际谱和冻结事件，回答：

- 主句是否大多数音都同一种短时值？有没有中途的目标长音、轻重标点、导向音及非结尾空位？全体声部不必同时停。
- 同一起音组内哪个才是主句？机械取最高音只能做代理；固定辅助音可能越过原意主线。不要把复音总数都称旋律数量。
- 重复的动机能否识别？A′具体保什么、改什么，展开是否来自原动机？每小节换一条新音阶不等于发展。
- 前景、内声和延续层是否整段一起常驻？主句长音/空位时哪一条线才移动，哪一层在内部退出？从头叠到底再末尾减鼓不等于段级层次。

这些是定位问题，不是分数或普遍审美门槛。固定短句、重复音、持续铺底也可能是风格选择。v9局部案例有49/50同短gate和两底层近全程常驻，与用户缺舒展反馈一致，但不能推广成“所有音乐都该减少音符”。统计不能反推听感。

## 复用的方法，落实到新谱

[DeSantis《Making Music》官方书](https://cdn-resources.ableton.com/resources/uploads/makingmusic/MakingMusic_DennisDeSantis.pdf)的前/中/背景、Contour、Using Motives、Multiple Simultaneous Melodies、Voice Leading和Harmonic Rhythm提供写作工具：建立可辨轮廓和动机；重复后只改部分；一条线延续时另一条运动；共同音与必要内声移动；把和声变化和表面重触发分开。这些是有例外的创作策略，不能当参考音符或固定流派公式。公开可读不等于许可再分发整本书。

[Belkin的作者教学建议](https://www.alanbelkinmusic.com/PDF/InstructorSuggestions.pdf)强调乐句标点和演奏呼吸；[其和声/织体/配器文章](https://alanbelkinmusic.com/general-principles-of-harmony-harmony-texture-and-orchestration/)说明音区、间距、加倍和配器一起塑造和声感知。因此新增声部必须有进入点、退出点和独立职责，不能仅贴乐器名。

可先写一个几小节的核心动机，给明确目标音与轻/重句尾；再作可辨重现和定向变尾；在少数位置展开或抬升。参考局部支持四小节重复尺度时，可用4+4+4作一次短样设计，但不能据此宣称原曲同形式或把古典sentence/period强套到所有电子BGM。主题和具体节奏/和声须重写，参考转录只作分析。

## 音色选择与演奏关系

按“必要职责→音区/起音/延续特征→真实资源→实际试奏”选择。更多颜色可能帮助，也可能让每层争抢注意力：

|需要解决的问题|可用动作|必须核实|
|---|---|---|
|长句听起来仍碎|改目标音与导向时值，选择能延续的音源，必要时让另一层承接|写长gate不等实际发声长；采样自身衰减、释放与混响须真测|
|所有前景起音都很重|取消固定叠音，选择性加强骨干或句头|不默认逐音叠钢琴；相同内容加倍不是新主题|
|回答不清楚|先在主句空位安排少量音并区分音区/力度；必要时替换回应音色|回答是否避开主句；不默认另加一条常驻对旋律|
|底层把变化抹平|保一个连续锚，其他层按句退出/重入，连接共同音|门控覆盖不等声学掩蔽或真实乐器数，渲染后再看活动窗|
|中段没有抬升|先考虑音域、节奏、力度与织体变化，再给少量延续/色彩进入|最高音/大音量/更多轨都不单独等于情绪成立|

已有音源技术控制仅支持对应音区/力度。普通normal采样不承诺真实连奏、弓法、踏板或演奏者表情；不改名冒充其他民族乐器。来源许可、实际资源绑定和声音身份分开。

## 连续推动与接力先查什么

用户已经认可方向而继续要求连续、舒展时，先比较编译后的绝对起止帧。固定短门值可能在每小节末产生周期凹口；也可能被真实释放接住，不能只读谱下结论。用当前资源、原声部增益和同一混音口径做一次短机制控制，再到全混核对相应边界及错相负控。原生声部诊断已经包含原生master，不得重乘一次。采样区的release参数、门值覆盖或低频功率均不独立证明声音连续、音符身份或风格。

确认是不必要的门间隙后，可只将选定持续音接到下一起点，保既有音高、力度与逐击让位；收束或有意休止另列。不要为“推动”猜加原曲经过音、每个底鼓都重弹低音，或把延长全体门值当普遍配方。[DeSantis的官方书](https://cdn-resources.ableton.com/resources/uploads/makingmusic/MakingMusic_DennisDeSantis.pdf)第158–162页用鼓低音复合线展示作曲层的分工；其互斥起音只是特定策略，本曲采用哪一种必须看真实参考，不机械套用。

主句目标与回答写成精确事件：保留哪个目标音，延展多少，删除的是弱导向还是强重复，哪些同起内声必须退让；回答从哪里进入、何处退出、是否有意交叠。注明小节/拍用一还是零起算，同时给tick或帧。无新起音、音符关门、采样释放和绝对静音是四件不同的事。[Belkin《配器理论》](https://alanbelkinmusic.com/PDF/BelkinOrchestrationTheory.pdf)对前中背景的区分、有限背景活动及不同节奏/音区的主次关系，适合指导接力；不能反推参考一定使用哪件乐器。只改变少数有职责的位置，核现有真实音源在活动窗的贡献，避免每两小节机械套同一个呼吸模板。

## 编排计划与 `arrange-check`

写谱前把声部职责写成一份独立的编排计划 JSON（不改乐谱 schema），写完谱用 `band.py arrange-check --score <谱> --plan <计划> --out <新报告>` 只读谱面核对。计划字段：

- `profile`：`ensemble`（默认）或 `sparse_solo`。独奏、二重奏这类稀疏作品用后者，锚点数值只报告不提示。
- `roles`：每个声部的职责，取 `foreground / answer / bass / harmony / rhythm / color`。
- `sections`：可选，逐段写 `foreground`（谁是这段的主句）和 `roles` 覆盖，用来声明交接。每段都要有前景，否则计划被拒。
- `peak_section`：可选，唯一高峰所在段。
- `motifs`：可选，`[{motif_id, part_id, intervals, min_occurrences}]`，`intervals` 是半音音程序列。

检查分三级：计划自己声明了却没做到的记「不通过」，经验阈值记「需核」，分不开认可与否决的量只「仅报告」。

| 检查 | 判定 | 含义 |
|---|---|---|
| `answer_onset_collision` | 不通过 >0.25 | 回答声部的起音落在前景起音 ±1/8 拍内的比例；回答应在主句空位进入 |
| `peak_reaches_top` | 不通过 | 全曲前景最高音不在声明的高峰段 |
| `unique_peak` | 需核 | 最高音在多个段落都出现 |
| `motif:<id>` | 需核 | 动机原样出现次数不足，或从未变尾重现（变尾只在动机 ≥3 个音程时判定） |
| `handoff:a->b` | 需核 >1 拍 | 前景换人时，前一位最后发声到下一位第一个起音之间的空档 |
| `register_masking` | 需核 >0.35 | 非前景声部在前景 ±2 半音内同时发声的比例 |
| `anchor:registers_ge3_share` / `polyphony_mean` / `foreground_long_note_share` | 需核（≥0.5 / ≥3.5 / ≤0.5） | 认可作品与否决作品之间分得开的三个谱面量 |
| `bass_presence`、`anchor:onset_density_per_s`、`anchor:velocity_std` | 仅报告 | 谱面口径下分不开；低频要看渲染后 `check` 的 <120 Hz 能量 |

阈值来自 3 首认可、2 首否决作品按自动计划重算的对照（`work/主流乐团完善_20261103/编排检查/evidence/calibration.json`），样本少、风格杂，所以锚点只作「需核」。校准结果：折线、灯火通过；向光只有 `unique_peak` 需核（最高音 82 在 7 段都出现）；两首否决作品在音区数、复音数、长音比三项都需核；待验的星河遮蔽 0.541 需核。

这份检查回答「计划写的关系谱面上有没有做到」，不回答「计划对不对」「好不好听」。通过不等于听感通过；需核项写进作品检查，说明是有意为之还是要改。

## 一次短样怎样验

在写谱前为本曲约定可检查动作，例如两个中途主句呼吸、可辨首部重现、少量长短目标、内声/延续层真正内部退场。具体数量由音乐决定，不做所有作品硬门槛。将约定、角色进退表和变更证据随作品保存。

语义/冻结/实际采样区域通过后，一次真实合奏，核音符gate之外的有效发声与声部活动窗/峰值。全长RMS不能直接判主次，尤其是稀疏回答；需要时看实际活动段。只对已定位的音量/削波/资源问题修正，不反复抽歌追漂亮指标。原曲/新作对照采用等长主体窗口和常数增益，不能拿成品尾音与参考曲中段证明呼吸。

最后分开记录：技术检查、来源/创作审查、人工音乐方向。未听辨不声称好听或风格通过；已有整体否决、方向仍未解决时不展开长曲。正常已授权创作不额外新增预览审批。若同法两次实质修正仍无改善，保留失败及决定依据，重新查缺少哪种证据，不再靠换preset或加轨尝试。

## 主句被鼓打断与音调发展

先读实际效果目标，分清哪个声部真的被duck；未经路由的主旋律不能被口头归因为全键侧链。逐个代表重拍核前后门控、真实发声和下个旋律起点，并与参考mix/估计/残差的同窗频率活动交叉。参考有调层也会自然起伏、换音或短让位，不能要求平坦恒强；分离器下落不等原旋律被压缩，实际带内能量混有内声，心理声学掩蔽还需另验。

定位为不必要的早关门时，可让少数已响目标跨过重拍再留短呼吸；定位为末填鼓在主音结束后继续渐强、却没有下一落点时，可把填鼓移到目标之前，让旋律完成落点。不同句子采用不同处理，不将所有休止填满或所有鼓全局降低。[Berklee的节奏分句方法](https://college.berklee.edu/bt/193/lesson.html)支持用重音、休止、时值和非第一拍起句摆脱小节线束缚，不能照搬其练习节奏来代表参考风格。

需要更丰富的主句时，上一轮“所有主题音全保”只是一轮约束；用户已要求发展时，明确保留可辨动机，允许局部节奏变形、目标延展、解决与变尾，保存逐音差异。可保同一开头而发展后半，或用一次明确趋向音解决，避免把音阶随机加长当丰富。新增低于旧音高阈值的主题音仍是主题，应使用明确ID集合，不能再机械按最高音或MIDI阈值分类。[Ableton的轮廓方法](https://makingmusic.ableton.com/creating-melodies-1-contour)是带例外的平衡工具，不是每首都只能有一个高点的硬规则。

自然衰减的采样不能只靠长gate保持音体。必要时可让已有持续声部在一个目标上选择性承接，再跨下一声部/下一拍短暂交叠；不要逐音叠整首或加全程pad。相同pitch跨音源仍可能有相位、身份转换及掩蔽，技术控制的力度/零起点不能外推实际全混。谱面同时四个gate不等证明四个独立声音；应核目标在该窗是否真实继续、当前state/音区/力度与成品诊断是否对应，融合及好听仍由人工验收。

## 主旋律节奏偏离参考时

先把谱面起点、实际发音建立和听觉节奏分开核查：同一八拍起点模板反复换音高，不自动产生节奏发展；已有大量伴奏起音，也不等主句有可辨推动。用参考混音与不同估计源互证短触发、较长目标及跨重音接续，保留鼓泄漏。起音方法须先在自有已知事件上校准，额外峰不能直接转原曲MIDI，更不能靠峰数匹配签风格。

[Sioros等2014旋律实验](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2014.01036/full)比较选位切分、全线错位和同音增加密度：可借乐句边界的定向提前、短长张力及回到锚点，不将切分总分、密度或更多时值当最佳公式；时值多样性的独立贡献仍不确定。[Danielsen等2019研究摘要](https://pubmed.ncbi.nlm.nih.gov/30802130/)提示起音形状与时长也影响节奏定位。包络峰、能量中位和阈值不是已测人类P-center，不能把所有音统一提前同一毫秒数。

若名义短音接近该音色实际音体建立时间，先核真实采样及现有包络控制；参数可读回不等这个采样变成快起。慢起来自录音时，可保完整主奏的旋律/长目标，用已有合适资源承担少数结构性前体；新增攻击须对应明确自有主题ID/起点/音高，不能全线复制或撤主奏。实际核新增部分发音与合奏，保持未受影响声部，并区分语义保留、波形变化与人工音乐验收。
