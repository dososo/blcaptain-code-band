# 葫芦丝有限音区原型：CC0

来源：[Chinese flute Hulusi](https://freesound.org/people/iluppai/sounds/180239/)，上传者 iluppai，2013-03-08，页面声明 CC0 1.0；下载的是公开可直接访问的高码率 MP3 试听副本，不是需登录的原 WAV。作者声明为葫芦丝独奏；未独立核查演奏者身份、混音及真实音准。

从原独奏中截取五段单一稳定音高（MIDI 69、72、74、77、79），不复制整段乐句；每段去除原起音和部分尾部，施加短切边淡入淡出、立体声合单声道、转16位PCM，不跨键插值，不含循环、力度层、自动轮换和可控滑音。Freesound MP3预览为有损，不能当作原无损WAV；真实音色及录音是否含底噪/伴随管，需人工试听。此为CC0素材衍生有限原型，不代表完整葫芦丝或原始演奏技法。
