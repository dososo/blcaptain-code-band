# Sonic Pi 塔布拉采样许可

原采样发布者 Sonic Pi 的 `etc/samples/README.md` 声明采样为 CC0 1.0，并逐条列出原作者 dio_333 与 Freesound 声音链接；固定版本及每文件哈希详见 `来源与映射.json`。本转换保留原采样内容，映射为固定鼓键，不以演奏法完整或新录音误称。源音频为44.1kHz/16位单声道；导出48kHz/24位不意味着提高采样源精度。
