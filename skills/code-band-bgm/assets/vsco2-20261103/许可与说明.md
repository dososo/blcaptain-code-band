# VSCO-2-CE 乐器库（SF2 转换版）

- 来源：VS Chamber Orchestra: Community Edition，https://github.com/sgossner/VSCO-2-CE ，SFZ 分支，提交见 `build/来源.json`。
- 录音：Sam Gossner、Simon Dalzell；切片：Elan Hickler/Soundemote。
- 许可：CC0 1.0（官方 LICENSE 已直读，副本见 `build/LICENSE`）。上游 Readme 另请求不要直接出售样本，属请求，不是许可条件。
- 转换：映射取自 SFZ；八度按全乐器众数统一，音分按采样实测校正；连续音烘入 80 ms 交叉淡化循环；样本转 16 位，最长 8 秒。
- 已知限制：
  - 无真实连奏录音，也无圆号组、长号组，圆号和铜管都是独奏；
  - 循环段是合成结果，多件乐器长音可能听出周期；
  - 人工听感未验收。
