# 古琴 GuqinSonGest v1 音色库：许可与说明

## 来源与许可

- 数据集：GuqinSonGest: A multimodal and historically grounded dataset of guqin playing techniques
- 地址：https://zenodo.org/records/14962054（DOI 10.5281/zenodo.14962054，发布日期 2025-05-28）
- 许可：CC BY 4.0（`cc-by-4.0`）。2026-11-03 直接读取 Zenodo 官方 API `https://zenodo.org/api/records/14962054` 核验，元数据副本：`work/Claude交付_代码乐团_20261103/evidence/guqin/zenodo_14962054_metadata.json`（不随技能分发）。
- 作者：Han, Han。贡献者：You, Liyu（Zenodo 标注为 Researcher；此前调研称其为演奏者，**待确认**）。
- 署名要求：分发本 SF2 或用它渲染的作品时，注明「古琴采样来自 GuqinSonGest（Han Han，Zenodo 14962054，CC BY 4.0），经代码乐团切取、校音、制成 SF2」。
- 修改说明：取原始 48 kHz 单声道 WAV 的单次拨弦；40 Hz 二阶高通；起音前留 3 ms；截至 8 秒，尾部 0.6 秒余弦淡出；按实测音高逐条校正到十二平均律（原定弦整体约低 20–40 音分）；增益归一到起音段 −18 dBFS RMS。

## 内容

- 文件：`Guqin-GuqinSonGest-v1.sf2`，SHA-256 `1ab5d728d8f7651b8e77beb945139f5d577060a69f530caaa836e370c0952e32`
- program 0/1/2「Guqin Pluck A/B/C」：同一力度、同一组根音的三组轮换（不是力度层）；录音不足三条的根音循环复用，只剩一条录音的根音没有轮换。
- 首次构建曾把第三条录音挂在 96–127 力度区，会被矩阵误计为 3 个力度层，已改；旧文件在 `superseded_velocity_split/`。
- 实录根音 11 个：36、41、43、45、48（散音），50、53、57、59、65、74（按音）。键域 31–79，最大移调 5 半音。
- 逐条测量：`采样测量_v1.json`（源文件 SHA-256、实测音分、校正量、区域音高核验结果）。
- 构建脚本：`build/构建.py`，需用 `--source` 指向自行下载的 GuqinSonGest WAV 目录；源 WAV 不随技能分发。

## 已知限制

1. 不是全音域半音表：11 个根音之间最大间隔 9 半音（65→74），中间的键靠移调。
2. 剔除了 9 条录音（见 `采样测量_v1.json` 的 `excluded`）：区域音高核验在根音附近测到同强或更强的另一个音高。可能是按音起音时的绰（自下滑入）或其余空弦的共鸣，**未经人耳确认**。因此 G3（55）和 C4（60）没有实录，用相邻根音移调；G2（43）、C3（48）只剩一条录音，没有轮换。
3. 泛音没有纳入：4 条一弦泛音只有 1 条通过核验，不足以单独成为奏法。
4. 吟猱、绰注、上下滑音只录在数据集里，未做成采样奏法；吟猱参数测量离散（`evidence/guqin/yinrou_summary.json`），`idiomatic.py` 中仍为假设值。（v2 已解决，见下节）
5. 只有一种力度层；人工听感未验收。
6. 2026-11-03 v2 构建时发现：v1 起音阈值「首次超过峰值 −30 dB」落在录音开头的底噪里，25 条拨弦中有 11 条（36–50 的散音与低按音）从底噪开始，晚出 0.13–0.6 秒，这几条的音量归一化也量在底噪上，增益偏大 3–7 dB。v1 文件不改（已被认可的作品引用它）；新作品改用 v2。

# v2：泛音、吟猱、绰（2026-11-03）

- 文件：`Guqin-GuqinSonGest-v2.sf2`；摘要以 `soundfont-packs-20261103-v22.json` 为准。逐条测量：`采样测量_v2.json`。构建：`build/构建_v2.py --source <WAV 目录> --techniques <测量 JSON>`。
- 来源与许可同 v1（GuqinSonGest，CC BY 4.0），署名要求不变。
- 修改说明（与 v1 不同处）：起音改为「粗起点后 3 秒内 2 毫秒包络最大处，往回 60 毫秒内首次达到峰值 −15 dB」，起音前留 5 ms、淡入 2 ms；拨弦、泛音的音高校正量在裁切后 0.1–1.1 秒窗测得。
- program 0–2 拨弦（选音与剔除表同 v1）；3 泛音；4 承声吟；5 声后吟；6 绰。

| 奏法 | 根音 | 键域 | 怎么来的 |
|---|---|---|---|
| harmonic | C3 G3 C4 D4 G4 C5 D5 B5 | 46–50、53–76、81–85 | 98 条可用泛音里，实测音级须与标注音名一致（29 条不一致被拒，多为双弦泛音或七分音徽位）、起音后两个 1 秒窗音高相差 ≤30 音分、偏离 ≤35 音分，并单独通过区域音高门禁 |
| yin_chengsheng | D3、D5 | 47–53、71–77 | 测到周期摆动、半周期最多的一条 |
| yin_shenghou | D5 | 71–77 | 同上 |
| chuo | D3、D5 | 47–53、71–77 | 全音滑入（起点低于目标 150 音分以上）的录音 |

- **吟的音高基准**：实测古琴「吟」从本音往上摆——9 条吟猱摆动下沿的中位数都在本音 ±30 音分内，上沿约 +85 至 +125 音分；声后吟起摆前的稳定段在本音上（−10 至 +3 音分）。所以采样以摆动下沿对准谱面音高，不用摆动中心。`idiomatic.guqin_yin` 的模拟也按此往上摆（全扶往下摆）。证据：`work/主流乐团完善_20261103/guqin/evidence/techniques_v2.json`、`calibration_v2.json`。
- 逐音渲染核验：`work/主流乐团完善_20261103/试听/r3/evidence/guqin_pitch.json`，17/17 通过（音高 ±25 音分、起音 ≤50 毫秒、吟的摆动下沿在本音上）。

## v2 已知限制

1. 吟猱、绰只有 D3、D5 两个根音，每个只覆盖 ±3 半音；其余音须用 `idiomatic.guqin_yin`／`guqin_chuo` 的实测参数在拨弦上模拟。声后吟在拨弦上模拟时，0.87 秒后才起摆，摆动落在已衰减 30 dB 以上的余音里，听感偏弱。
2. 泛音 51–52、77–80 没有覆盖。
3. 吟以下沿对准本音是按录音事实定的；若听感上觉得「吟」整体偏高，可改为以摆动中心对准，**待人耳确认**。
4. 只有一种力度层；人工听感未验收。
