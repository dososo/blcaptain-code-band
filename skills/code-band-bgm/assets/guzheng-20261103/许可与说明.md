# Pufermufin 古筝完整切片（第二版）

- 来源：Freesound 396868，作者 Pufermufin，CC0-1.0（核验记录见 `../chinese-expansion-20261031/古筝Pufermufin许可与说明.md`）。
- 输入：作者公开 HQ 预览 MP3（约 126 kb/s），有损，非原始 WAV。
- 制作：从全长录音（有效内容约 1170 秒）挑选可分离的独立拨弦，14 个根音 23 个采样；取至下一起音之前，尾音因此有限；未取旋律句，保留录音自身的环境与上一音余响。
- 处理：70 Hz 四阶零相位高通（去录音次声），按起音后 20–300 ms 的电平统一，末尾四分之一渐弱（切点处弦仍在响）。
- 实录调弦：D F G A C 五声，比标准音高约 11 音分，已用 SF2 音高校正抵消。
- 真实录得的只有普通拨弦和力度差。按滑、吟揉、摇指都是演奏控制或重复触发，不是录制的奏法。
- 已知弱点：
  - 根音 45/48/50/62 的基频弱（测音高用了二次谐波），低音区偏薄；
  - 根音 50 和 69 的尾音不足 1 秒；
  - 根音 79 比标准音高 39 音分，已校正，可能是按音，待人工确认；
  - 全库 16 位，声像取自录音，没有全 21 弦和全音区；
  - 77–82 全部由根音 79 移调得到。
- 人工听感：未验收。
