# Meta Piano v1.0.0 音源许可与转换

音源由 Meta Open Sound 发布，发行版 `meta-piano-v1.0.0`，<https://github.com/facebookincubator/Meta-open-sound/releases/tag/meta-piano-v1.0.0>。官方说明此钢琴采样以 CC0 1.0 Universal 发布，<https://creativecommons.org/publicdomain/zero/1.0/>。官方WAV压缩包752311261字节，SHA-256 `ee9023dbde849ecab393a098aa0cfbd6f2ef48d4a096b9c08808b72fc913f70e`，本机已与官方发行API一致。官方SFZ与说明取固定提交 `e2ff154845994fe4135becc4d5b857c19f172784`。

官方素材为88键A0–C8、每键四个独立力度录音、48kHz/24位立体声。此项目以libsndfile解码转换为16位PCM，不加降噪/修音，左右声道分别建立独立样本区并以极左/极右声像输出；每个采样只映射其官方根音，分层为1–31、32–63、64–95、96–127。采样来源及逐音SHA见`逐源映射.json`。

**转换限制**：本库为16位而非原24位；不实现官方SFZ等功率跨力度层渐变、随机音高/音量微扰，也未复制SFZ `amp_veltrack=0`，所以FluidSynth默认速度增益/滤波可能叠加于层选择。两声道使用独立单声道样本、极左/极右区域，不是官方立体声SFZ实现的逐样等价；无单独踏板/自然释放触发或自动轮换。SF2包络采用约1ms攻击、35ms释放，非官方SFZ声学等价验证；未对所有键及力度进行人工听感。

构建使用项目先前取得的SF2cute Zlib库，源文件 `SF2打包器.cpp` 与 `SF2cute-Zlib许可.txt` 保留版权和许可证。本库仅在音频与授权技术范围有限接入，不保证是参考作品主音，不暗示Meta背书。
