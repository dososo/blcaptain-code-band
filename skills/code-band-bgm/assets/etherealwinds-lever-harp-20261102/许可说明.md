# Etherealwinds 拨杆竖琴

作者 Jordi Francis（Etherealwinds）与 Versilian Studios LLC 的 [Etherealwinds Harp II: Community Edition](https://versilian-studios.com/etherealwinds-harp/)；官网许可 CC BY 4.0，https://creativecommons.org/licenses/by/4.0/ 。录音为34弦 Iona 凯尔特拨杆竖琴；已按原SFZ选取每力度层首轮换，转为16位立体声 SF2。原库2力度层、2轮换，本包保留2力度层、每层1个轮换；未复刻原音量和释放包络，人工听感待验。来源和逐音 SHA 见来源与映射.json。
