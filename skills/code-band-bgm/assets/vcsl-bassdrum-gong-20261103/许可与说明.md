# VCSL 音乐会大鼓与锣（SF2 转换版）

- 来源：Versilian Community Sample Library，https://github.com/sgossner/VCSL ，提交 `c1ea7bcc3c7309650ab0da9d15c9cd1fbc4a4c7e`（浅克隆稀疏检出，仅取 Bass Drum 1、Bass Drum 2 的 hit/roll、Gong 1）。
- 许可：CC0 1.0（上游 LICENSE 已直读，副本见 `build/LICENSE`）。
- 内容：
  - 键 36：Bass Drum 1 单击，4 力度层 × 2 轮换（program 0/1）；
  - 键 35：Bass Drum 2 单击，5 力度层，pp/mp/mf 有 2 轮换；
  - 键 37：Bass Drum 2 慢滚奏，4 力度层；键 38：快滚奏，4 力度层；
  - program 2/3：Gong 1，键 60 单击 4 力度层（mf、f 有替代击），键 61 刮奏。
- 转换：去掉起音前静音（-40 dB 阈值、留 2 ms），截断到 6—16 秒并余弦平方渐弱，未做音高或均衡处理。
- **身份**：这是西洋音乐会大鼓和锣，**不是中国大鼓、堂鼓或京锣**。用在民族作品里只能写作「低频鼓替身」，并在清单中标明。
- 已知限制：滚奏是固定长度录音，不能任意延长；锣截断到 16 秒；人工听感未验收。
