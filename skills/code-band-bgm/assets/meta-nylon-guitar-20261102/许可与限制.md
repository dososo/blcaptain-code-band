# Meta 尼龙弦吉他来源与限制

[Meta官方 v1.0.0](https://github.com/facebookincubator/Meta-open-sound/releases/tag/meta-nylon-guitar-v1.0.0) 提供 CC0 1.0 实录，许可正文见 `LICENSE-CC0.txt`。官方 WAV ZIP 的 SHA-256 为 `d76a23d438c7e6002aad61c564173141daac3a89f7bae5400f996d1a59b4eb76`，本地下载摘要与发行元数据相符。

本转换仅使用官方SFZ默认第一通道的 44 键、每键三个独立指弹/拨片录音，共132个立体声样本；48 kHz 24 位转换为 16 位，保留左右声道。按力度 1–42、43–85、86–127 硬切，非官方交叉淡化；不实现原 SFZ 的单弦通道、弦间抢占、键开关、随机微调和完整 one-shot 控制。不能声称与官方 SFZ 的演奏行为或声学细节相同。可播放范围 MIDI 40–83；实际听感待验。逐样本摘要和音区见 `逐源映射.json`。SF2由 SF2cute 生成，其 Zlib 许可另附。
