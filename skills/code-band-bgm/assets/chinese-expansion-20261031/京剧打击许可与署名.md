## 真实资产与映射范围

官方按四类别分组：板鼓类（板+单皮鼓）59、大锣50、铙钹类（齐钹+大铙）62、小锣65，共236原录音。具体实例没有逐一标注子乐器、奏法、击打力度，不能凭文件编号或幅度发明标签。实际WAV为44.1kHz、32位浮点、单声道，与介绍中的16位说法不同；以实测为准。40份原音有1–18个恰满幅采样，未超出[-1,1]；是否上游归一化或曾削波未知，不声称修复原录音缺陷。PCM16采用乘32767取整，不新增超满幅或静默削波；原FLOAT32保留。

正式`Jingju-Percussion-CCBY3-v2.sf2`只映射174份起音清楚的独立击打：bank0/program0板鼓55，program1大锣30，program2铙钹30，program3小锣59。每类按原实例顺序落在触发键36起，但保留被拒实例产生的键位洞；真实键见`合并建议-第四批.json`。每个键只触发一份原速录音，根音字段是技术触发键，不是乐器可调音高。无移调、真实力度层、自动RR或完整京剧锣鼓经演奏法承诺。

62份音源从弱前导至持续主击打超过10ms，可能是自然慢起或前声，未知原因；不硬切至主峰，而保留原音并拒绝正式映射，证据见`京剧打击采样测量.json`。原未验收v1留工作历史，不作为正式库。正式样本按约1ms RMS检测明显前置静音，保留5ms；源弱至主起音≤10ms，加1ms包络及64帧调度后，实际174个触发的相对RMS起音均在20ms内。此阈值是技术测量，不是人工听感结论。

每个键门控会控制释放。要保留完整锣钹尾音，gate应至少为源`frames/44100`，详见逐样本测量；短gate会截短尾音，不能拿短门控声称完整原始击打。没有把延长gate作为前置静音的修复。

## 验证与重建

`build/准备京剧打击.py`离线验证原音hash、筛起音、准备PCM；`build/打包.cpp`调用固定SF2cute提交`3c5fc83b6ba3d1feb377f9c86021fd77499eb7c0`，仅薄写库，不实现采样器。上游原文Zlib许可随本包保留；构建静态库方法见`说明.md`。从项目根执行：

```sh
.venv/bin/python code-band-bgm/assets/chinese-expansion-20261031/build/准备京剧打击.py --work work/京剧打击重建
c++ -std=c++14 -I/path/to/sf2cute/include code-band-bgm/assets/chinese-expansion-20261031/build/打包.cpp /path/to/sf2cute-build/libsf2cute.a -o work/京剧打击重建/打包器
work/京剧打击重建/打包器 work/京剧打击重建/zones.tsv work/京剧打击重建/重建.sf2
.venv/bin/python code-band-bgm/assets/chinese-expansion-20261031/build/验证京剧打击.py --work work/京剧打击重建
```

选择不存在的新输出，保留旧库。验证命令检查本包正式v2，重建文件另以SHA256比较。174实例实际渲染、65,024组区域穷举、重复浮点渲染与重复SF2打包字节一致均通过；独立自编30秒四类打击WAV为48k/24位/双声道，见`京剧打击验证结果.json`。人工听感待验收；未宣称专业完整音源或所有权绝对保证。
