## 重建

从技能根目录使用已安装numpy/scipy/soundfile等依赖的Python、CMake、C++14编译器，以及固定[官方SF2cute源码](https://github.com/gocha/sf2cute/archive/3c5fc83b6ba3d1feb377f9c86021fd77499eb7c0.tar.gz)。完整上游源码不重复塞入本包。示例中`缓存/sf2cute-提交`应替换为自己解压后的源码目录，所有命令由参数数组执行，不拼用户文本为shell：

```sh
.venv/bin/python assets/chinese-expansion-20261031/build/重建.py --sf2cute-source 缓存/sf2cute-提交 --work 缓存/中国音色构建 --output 缓存/Chinese-Erhu-Guqin-v1.sf2
.venv/bin/python assets/chinese-expansion-20261031/build/验证.py --work 缓存/中国音色验证
```

验证脚本默认核查本包固定SF2；主程序拒绝覆盖已有输出。输入只需本包保留的原WAV/HQ预览及来源清单，不依赖原开发工作区。仅macOS本机实测，其他平台的音频哈希确定性未验证。

最小回滚：主注册解除本独立asset及五个资源绑定，保留资产和历史作品；无需改变主GM库。此目录的`合并建议.json`是待主代理检查的建议，不声称它已经修改共享注册。
