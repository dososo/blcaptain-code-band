# 中国音色扩展：许可与署名

## 二胡原录音及SFZ

来源：[SFZ Instruments / Aliexpress Erhu](https://github.com/sfzinstruments/aliexpress-erhu/tree/6615047b2fd06126877483e97b8bb4af9d00b080)，固定提交`6615047b2fd06126877483e97b8bb4af9d00b080`。作者描述为自己取得的廉价二胡、由主要学习小提琴的人演奏、近距立体声录音；不是专业二胡完整奏法库。

许可：[CC0-1.0原文](erhu-original/LICENSE)。原始`readme.txt`和官方SFZ全部保留。每个取得文件的原始URL、大小和SHA256见[二胡来源](二胡来源.json)。本轮取得65份24位立体声WAV，分别为长音20份、短音20份、靠指板奏法25份，每音每奏法选RR1；没有宣称接入RR2/3/4。

修改：按真实周期测量校准根音；修正作者文件名/原映射与常用MIDI八度体系的差别；保留单音起音前5ms；以中位音高偏差记录每样本细调补偿；保留立体声，下量化为SF2cute支持的16位PCM；无人工循环。marcato按官方方案以真实长音、真实短音分层，短层另设hold/decay/sustain。未复制官方CC连续动态、legato、unison和自动RR行为。

## 古琴七根空弦

作品：Guqin-open-strings.wav；作者：[RafaelCaro](https://freesound.org/people/RafaelCaro/)；来源：[Freesound 176266](https://freesound.org/people/RafaelCaro/sounds/176266/)；许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。作者声明2013-01-26于Cardedeu用Sony PCM D50近距录制自己演奏的七根空弦。没有取得或使用同一包中的《梅花三弄》歌曲。

本工程取得公开HQ MP3播放预览，属于有损素材，原始WAV需要登录而未绕过。按七次拨弦截为独立音区，保留录音自然的前弦/共鸣余响；不是干净录音棚专业单音库。各弦只取下一次拨弦前的有限片段，实测根音C2/D2/F2/G2/A2/C3/D3；半音映射最多移调1半音，范围MIDI36–50。无按音、泛音、吟猱、滑音或全音域承诺。

修改：单音裁切、起止微小退淡、音高中位偏差补偿、16位PCM量化与SF2立体声映射。完整来源/音频与网页哈希见[古琴来源](古琴来源.json)，逐弦裁切和测量见[采样测量](采样测量.json)。

再分发本扩展或使用其古琴录音生成作品时，请随附以下署名和修改说明：

> 古琴音频源自RafaelCaro的“Guqin-open-strings.wav”（Freesound 176266），采用CC BY 4.0许可。原作者来源：https://freesound.org/people/RafaelCaro/sounds/176266/ 。许可：https://creativecommons.org/licenses/by/4.0/ 。本项目进行了单音裁切、音高细调、格式量化和采样映射；作者未为本项目或新作品背书。
