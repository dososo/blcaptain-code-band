# GMD闭镲条件统计

来源：Google LLC 发布的 [Groove MIDI Dataset](https://magenta.withgoogle.com/datasets/groove)，CC BY 4.0；许可原文：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode)。学术署名：Jon Gillick、Adam Roberts、Jesse Engel、Douglas Eck、David Bamman，Learning to Groove with Inverse Sequence Transformations，ICML 2019。

本文件夹数据沿CC BY 4.0，不以项目代码许可覆盖。本项目从drummer3/session2/40_hiphop_110_beat_4-4.mid提取闭镲按拍位的样本数、相对力度和相对时间偏差；不是完整MIDI或音频，不含用户参考。具体文件摘要在JSON。转换有改动：按类中心化、输出统计；运行时另有保守限幅及边界保护。

单人单段110BPM hiphop经验不代表原曲或所有流派；不会自动签收风格。使用该数据制作的作品应随作品保留此来源、署名、许可与变更说明。不捆绑GrooVAE权重或其输出。
